## 5화 및 새 게임 규칙 — 이미지 생성 복구

초기 API 오류가 복구됐다. 사용자 재확인을 요구하지 않고 필수 신규 이미지 제작을 마쳤다. 5화용 손견·화웅 참조 2개와 보급·화웅 도전·삼영전여포 장면 3개를 생성·직접 열람·연결했다. 별도로 1~5화의 단독 인물 표시를 교체할 환경 장면 5개를 생성했다. 삼영전여포는 첫 생성본의 보병 표현을 기마전으로 수정했다. 전체 생성 자산은 25개이며 새 참조 2개는 게임 표시용이 아니다.

기록 기본 5초, 선택 결과 고정 5초, 모든 옵션 이미지 유지, 선택별 스탯 비중·난도와 영향력별 명성 보상, 실패 시 정확히 절반 차감 규칙을 1~5화 전체에 반영했다. 상세는 `game-rules-20261022.md`와 `data/chapters/balance-review.json`에 있다.

추가 이미지 QA에서 동탁 본인의 위치와 사수관 연락소의 시점이 섞일 위험을 발견했다. 일반 연락관과 관문·지도·수레가 있는 `r005-dong-liaison.png`를 새로 생성·직접 열람해 7개 동탁군 보고 장면에 연결했다. 신규 자산 총 11개(환경 9·참조 2)이며 배포 전 5화 화면을 다시 검증한다.
