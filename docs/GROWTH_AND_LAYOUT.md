# 캐릭터 정보와 선택 성장

## 이름 입력과 모바일 배치

이름 입력은 타이틀 본문에 붙은 폼에서 공통 `GameDialog`로 이동했다. PC·모바일 모두 화면 중앙에서 입력하며, 취소·Escape·바깥 클릭을 지원한다. 모바일 정보는 `이름 · 나이 · 위치 · 통/무/지/정/매 수치 · 명성 · 정보 아이콘` 한 줄이다. 능력 이름은 통·무·지·정·매, 명성은 명으로 줄인다. 아이콘 버튼은 기존 캐릭터 정보 팝업을 연다. 증감 반짝임은 이 한 줄의 실제 숫자에 적용하고, 별도 결과 알림 줄은 표시하지 않는다. 팝업에서는 전체 능력 이름으로 표시한다. 펼치기 UI는 사용하지 않는다.

모바일의 자동 재생·속도 배율·다음 기록 제어는 설정 팝업으로 옮겼다. PC는 상단 제어도 유지한다. 설정에서 속도·자동 여부를 바꿔도 같은 재생 상태를 사용하며, 다음 기록 버튼은 설정 팝업을 닫고 실제 다음 기록으로 진행한다.

## 성장 기준

- `lib/choice-growth.ts`에서 56개 선택지의 행동을 통솔·무력·지력·정치·매력 중 관련 능력에 연결한다.
- 판정 성공은 관련 능력과 명성 +2, 일반 선택·실패 경험은 +1이다.
- 결과 노드가 같은 능력이나 세력 평판을 이미 지급했다면 중복 지급하지 않는다. 기존 결과의 +3·+5·+10 능력과 +20 평판은 +2로 조정했고 원본 문구·재생성 스크립트도 맞췄다.
- 명성은 소속과 별개인 활동 누적값이다. 새 게임은 0이며 이전 저장에 값이 없으면 0으로 이어간다. 세력 평판은 기존 `reputation`에 별도로 보존한다.
- 능력치는 100 상한을 유지한다. 실제로 오르지 않은 수치는 증가했다고 표시하지 않는다.
- 선택 기록의 `growth`에 실제 증감을 저장하고 같은 선택 키를 다시 보내도 중복 지급하지 않는다. 과거 기록을 다시 읽는 것으로 보상하지 않는다.
- 수치 증가는 녹색, 감소는 빨간색으로 두 번 은은하게 반짝인다. 모바일에서는 한 줄에 나온 숫자만 반짝이며 별도 증감 배지나 보상 알림 행은 표시하지 않는다. PC 상세 정보에서는 숫자 옆에 변화량도 표시한다. 동작 줄이기 설정에서는 애니메이션을 생략한다.
