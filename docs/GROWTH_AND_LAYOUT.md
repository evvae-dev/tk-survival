# 캐릭터 정보와 선택 성장

## 이름 입력과 모바일 배치

이름 입력은 타이틀 본문에 붙은 폼에서 공통 `GameDialog`로 이동했다. PC·모바일 모두 화면 중앙에서 입력하며, 취소·Escape·바깥 클릭을 지원한다. 모바일 정보는 `이름 · 나이 · 위치 · 통/무/지/정/매 수치 · 명성 · 정보 아이콘` 한 줄이다. 능력 이름은 통·무·지·정·매, 명성은 명으로 줄인다. 아이콘 버튼은 기존 캐릭터 정보 팝업을 연다. 증감 반짝임은 이 한 줄의 실제 숫자에 적용하고, 별도 결과 알림 줄은 표시하지 않는다. 팝업에서는 전체 능력 이름으로 표시한다. 펼치기 UI는 사용하지 않는다.

모바일의 자동 재생·속도 배율·다음 기록 제어는 설정 팝업으로 옮겼다. PC는 상단 제어도 유지한다. 설정에서 속도·자동 여부를 바꿔도 같은 재생 상태를 사용하며, 다음 기록 버튼은 설정 팝업을 닫고 실제 다음 기록으로 진행한다.

## 성장 기준

- `lib/choice-growth.ts`에서 56개 선택지의 행동을 통솔·무력·지력·정치·매력 중 관련 능력에 연결한다.
- 판정 성공은 관련 능력과 명성 +2, 일반 선택·실패 경험은 +1이다.
- 결과 노드가 같은 능력이나 세력 평판을 이미 지급했다면 중복 지급하지 않는다. 기존 결과의 +3·+5·+10 능력과 +20 평판은 +2로 조정했고 원본 문구·재생성 스크립트도 맞췄다.
- 명성은 소속과 별개인 활동 누적값이다. 새 게임은 0이며 이전 저장에 값이 없으면 0으로 이어간다. 세력 평판은 기존 `reputation`에 별도로 보존한다.
- 능력치는 100 상한을 유지한다. 실제로 오르지 않은 수치는 증가했다고 표시하지 않는다.
- 선택 기록의 `growth`에 실제 증감을 저장하고 같은 선택 키를 다시 보내도 중복 지급하지 않는다. 과거 기록을 다시 읽는 것으로 보상하지 않는다.
- 수치 증가는 녹색, 감소는 빨간색으로 두 번 은은하게 반짝인다. 모바일에서는 한 줄에 나온 숫자만 반짝이며 별도 증감 배지나 보상 알림 행은 표시하지 않는다. PC 상세 정보에서는 숫자 옆에 변화량도 표시한다. 동작 줄이기 설정에서는 애니메이션을 생략한다.

## 새 게임의 능력치 룰렛

이름 입력 뒤 `StatRoulette`가 자동으로 돌아가며 통솔·무력·지력·정치·매력을 각각 30~80(양 끝 포함)에서 독립 추첨한다. 약 3초 동안 하나씩 멈추고 확정값을 보여준 뒤 첫 선택 팝업을 자동으로 연다. 확정값은 가정 보정을 더하지 않고 그대로 저장한다. 애니메이션의 임시 숫자와 최종 추첨값은 분리한다.

시작 위치와 출생 위치는 `unknown`(모름)이다. 전선 이동 선택 뒤 실제 위치가 정해진다. `introChoicePending`은 새 게임에만 사용하며 첫 선택을 처리하면 해제한다. 기존 진행 중인 저장의 능력치를 다시 추첨하지 않는다.

룰렛에는 닫기·재추첨 버튼이 없고 Escape·바깥 클릭으로 중간에 닫히지 않는다. 동작 줄이기 설정에서는 숫자 순환을 생략하고 더 빠르게 확정한다.

검증: `node .agents/skills/playwright-page-check/scripts/check-onboarding.cjs http://localhost:4173 /tmp/tk-onboarding`. PC·390px·320px·동작 줄이기에서 룰렛 숫자 범위, 표시 확정값과 저장값 일치, 모름 위치, 첫 선택 자동 진입을 확인한다.

능력치 확정 후 첫 상황을 배경으로 검은 눈꺼풀이 두 번 깜빡이고 서서히 열리는 2.6초 전환을 표시한다. 전환 중 입력과 기록 재생을 막고, 완료 후 첫 선택 팝업을 자동으로 연다. 동작 줄이기 설정에서는 0.3초 페이드로 대체한다.

게임 완료 화면은 ‘나의 기록’ 대신 이름이 붙은 연대기를 표시한다. 실제 저장 결과를 짧은 사건 문장으로 바꾸어 연도·월·발생 순서대로 묶는다. 전투 결과와 직접 참가·전해 들은 소식을 구분하며, 현재 5.1의 모든 결과를 대응시킨다. 기존 저장도 결과 본문으로 복원하며 알 수 없는 추가 사건은 원문을 보존한다. 1.5초마다 한 줄씩 나타나고 연대기 내부가 아래로 자동 스크롤된다. ‘전체 보기’는 즉시 전체 문장을 펼쳐 페이지에서 읽게 하고 ‘다시 재생’으로 처음부터 볼 수 있다. 동작 줄이기 환경에서는 자동 재생 없이 전체를 표시한다. 미래 연도는 실제 기록이 있을 때만 표시한다.
