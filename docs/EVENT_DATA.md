# 역사·연의 사건 자료

## 현재 챕터 데이터와 담당 지시 — 2026-10-23

현재 원본 흐름은 `docs/romance-three-kingdoms/chapters/NNN.md` → `data/chapters/chapter-NNN.json` → `scripts/build-story.mjs` → `data/history/events.json`이다. 사실 대응은 `data/chapters/facts.json`에 둔다. 아래 2026-10-16 수량·5.1 설명은 과거 판본 기록이며 현재 실행 범위를 뜻하지 않는다.

데이터 담당은 [사건 참여 계약](EVENT_PARTICIPATION_CONTRACT.md)에 따라 사건별 성립 조건·참여 조건·진영/역할·불참 소식·취소 처리·조건별 실제 결말을 설계표로 명시하라. 이는 필요한 개념 목록이며 현재 JSON에 해당 이름의 필드가 모두 있다는 뜻이 아니다.

- 기존 조건 노드와 결과 효과로 표현하고 새로운 원본 필드는 생성기·검증기·관리자·저장 호환 지원을 확인한 뒤 추가하라.
- 처리 순서와 인과 조건을 구분하라. `prerequisiteEventIds` 또는 완료 표식만으로 접촉·동행·승리를 추정하지 말라.
- 중요한 표식은 생산 결과와 소비 조건, 해제/유효 범위를 연결하라. `metLiuBei`와 참석 허락을 같은 의미로 쓰지 말라.
- 기본 NPC 결말은 세계 전제가 유지될 때만 적용하라. 공통 종료 효과로 다른 진영의 승패·생존을 덮어쓰지 말라.
- 인계 시 원본 항목→생성 노드→관리자 편집 위치를 적고 재생성 전후 의미 보존을 확인하라. 생성된 실행 목록만 손으로 고쳐 완료하지 말라.

후속 재개발 요청에 따라 현재 판본은 `romance-participation-v2`로 구현했다. 이전41건의 실행 정의와 QA 결과 파일은 폐기했으며 같은 사건 번호는 원작 단계 대응에만 사용한다. 새 QA와 검증은 [재개발 기록](development/rebuild-participation-1-5.md)을 따른다.

원본 JSON의 사건은 `requires`(세계 성립), `routes[].when`(참여·진영 우선순위), `routes[].region`/`entryEffects`(허가 후 진입), `choices[].conditions`(행동 자격), `outcomes[].when`(현재 세계 결말), `newsWhen`(불참 소식 관련성)을 지원한다. `requiredAlive`는 세계 생존 조건의 약식이다. 각 선택은 성공/실패의 `text`, `effects`, `artwork`를 가진다. 생성기는 이를 관리자에서 편집 가능한 공통 condition/choice/check/result 노드로 변환하며, 소식에도 동일한 조건별 NPC 효과를 적용한다. 원래 사건 취소에는 원래 세계 결말을 적용하지 않는다. 결과 그림은 실행 기록에 보존된다.

`prerequisiteEventIds`는 처리 순서만 정한다. 이전 사건 실패/불참도 처리 완료를 남기며, 후속 참석 권한은 별도 조건으로 읽는다. 소식·조용한 처리는 플레이어 명성·성장·소속·이동을 주지 않는다.

## 이전 판본 자료 기록

> 2026-10-16 현재 활성 범위는 184년·20세 테스트와 5.1 실행 사건 7개, 상위 연표 6개입니다. 장수 1,000명은 유지합니다. 이전 연간 성장·전체 연표 설명은 당시 기록입니다. 현재 구현·저장·편집 방법은 [5.1 실행 문서](CHAPTER_5_1_RUNTIME.md)를 우선 확인하세요.

2026년 10월 16일 기준 기본 사건은 276개(정사 214개·연의 62개)다. 사용자 요청에 따라 개인 사망 알림을 제외했다. 공식 참고 목록은 대응 188개·후보 1개·사용자 제외 1개로 구분한다. 아래의 초기 수집 수량은 구축 당시 기록이다.

사건 자료는 170~280년을 다룬다. 기존 134개 사건의 ID를 유지하고 정사와 연의의 사건·일화를 추가했다. 게임 대사나 위키 원문을 표시하는 자료가 아니라 한국어로 편집한 사건 목록이다.

## 파일과 필드

- `data/history/events.json`: 사건별 연도, 월, 날짜 정밀도, 지역, 세력, 관련 인물, 내용과 문헌 출처.
- `data/history/entities.json`: 지역·세력의 식별자와 한국어 표시명.
- `data/history/reference-catalog.json`: 삼국지14 공식 소개에 나열된 역사 이벤트 190개를 순서대로 대조한 한국어 참고 목록.
- `data/history/catalog-metadata.json`: 사건 수, 정사·연의 분류 수, 날짜 정밀도와 참고 목록 대응 현황.

`category`는 정사 계열 자료인 `history`와 소설 서사인 `novel`을 구분한다. 정사 본문과 배송지 주석의 인용 자료도 서로 같은 증거 수준으로 단정하지 않으며 `source.title`과 `source.record`에서 위치와 성격을 설명한다.

`source.title`은 사이트 주소가 아닌 문헌명이다. `source.record`는 중국어 원문이 아닌 한국어 기록 요약·해설이다. 사건의 내용과 함께 정사·연의 차이, 일화의 성격 또는 단정할 수 없는 부분을 설명한다. `relatedPeople`은 한글 인명 배열이다. 역병이나 일식처럼 특정 인물이 없는 항목은 빈 배열을 허용한다.

월을 확인한 사건은 `precision: "month"`와 음력 월을 기록한다. 월을 모르면 `month: null`을 사용한다. 연대가 느슨하거나 소설 장면을 역사 연대에 대응시킨 경우에는 `precision: "approximate"`와 `dateNote`를 함께 기록한다. 추가 일화의 근사 날짜는 삼국지14의 게임 발동 날짜를 확정 역사 연월로 가져온 값이 아니다. 윤월 번호가 불명확한 기존 사건도 설명을 유지한다.

## 공식 참고 목록의 범위

2026년 10월 15일 삼국지14 with 파워업키트의 공식 역사 이벤트 소개 페이지를 웹에서 열고 목록 항목을 메모리에서 세어 실제 190개임을 확인했다. 페이지의 중국어 원문이나 HTML을 저장하지 않았다. 한국어 제목은 목록의 소재를 알아볼 수 있도록 직접 옮겼으며 설명문·대사·게임 조건은 복제하지 않았다.

전체 사건은 289개로 정사 계열 227개와 연의 62개다. 공식 참고 190개 항목 가운데 46개는 기존 사건에 대응하고 143개는 새 사건에 대응한다. 나머지 1개는 게임의 가상 분기에 해당하여 `candidate`로 남겼다. 따라서 참고 목록 190개를 모두 대조했다는 뜻과 역사 사건으로 190개를 전부 확정했다는 뜻은 다르다. 후보에는 이벤트 ID를 배정하지 않으며 실제 게임 사건으로 끼워 넣지 않는다. 같은 사건을 다루는 여러 게임 항목은 하나의 기존 사건을 함께 참조할 수 있다.

후보는 다른 후계자가 등장하는 미녀 연환계의 가상 분기다. 곽가→유엽과 유엽→만총·여건은 연의 제10회, 노숙→제갈근과 장굉→고옹은 연의 제29회에서 추천 관계를 확인하여 소설 사건으로 수록했다. 「좋은 새는 나무를 고른다」는 연의 제14회에서 만총이 서황을 설득하는 장면에 대응한다.

## 확인한 원전과 한계

기존 편년 사건은 자치통감, 후한서 헌제기, 진서 무제기의 기존 편집 근거를 재사용했다. 기존 134개의 사서기록도 해당 문맥을 다시 읽어 문헌명·기년과 추가 경과, 후속 조치 또는 기록의 한계를 식별할 수 있도록 한국어로 보강했다. 역병·일식처럼 기사가 짧은 경우에는 병명·피해 규모·원인을 새로 만들어 채우지 않고, 문헌이 확인해 주는 범위를 설명했다.

웹 대조에는 삼국지 선주전·제갈량전·주유전·노숙전·태사자전과 삼국지연의의 도원결의, 동탁 암살, 관우와 화웅, 초선차전, 적벽, 계륵, 칠보시, 만두, 제갈량 사후 퇴군을 다룬 회차 등을 사용했다. 모든 추가 항목을 이번에 독립적으로 원문 대조 완료했다는 검증 표시는 하지 않는다. 문헌명이 적혀 있다는 것과 연대·세부를 완전 검증했다는 것은 구분해야 한다.

계륵은 연의 제72회의 양수 처형 장면과 정사 무제기 주석에 인용된 구주춘추의 철군 의도 해석을 별도 사건으로 기록한다. 양수의 처형에 관한 다른 주석 기록도 분리하여, 정사에서도 계륵 발언 때문에 곧바로 처형된 것처럼 연결하지 않는다.

## 기계 검증

`node scripts/validate-event-data.mjs`로 ID 중복, 연도·월, 분류, 한국어 출처·관련 인물, 지역·세력 참조, 원문·URL 필드 잔존, 참고 목록의 순서·대응·후보 상태와 메타데이터 수량을 확인한다. 이 검사는 사료 비판이나 개별 역사 사실 검증을 대신하지 않는다.
