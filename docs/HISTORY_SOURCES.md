# 역사 자료 정리 기준

게임에 필요한 자료는 한국어 사건 목록입니다. 중국어 원문 덤프와 사이트 URL 중심 색인은 사용하지 않으며 해당 파일과 수집 스크립트를 제거했습니다.

- `data/history/events.json`: 연월·지역·세력·인물·내용·문헌명·한국어 사서 기록
- `data/history/reference-catalog.json`: 공식 『삼국지 14』 역사 이벤트 190개 항목의 한국어 참고 목록과 사건 대응
- `data/history/catalog-metadata.json`: 분류·날짜 정밀도·참고 목록 대응 수와 검토 범위
- `docs/EVENT_DATA.md`: 출처 구분과 데이터의 한계

출처는 ‘정사 삼국지 촉서 관우전’, ‘삼국지연의 제72회’처럼 문헌으로 적습니다. `source.record`는 한국어로 다시 쓴 기록 요지이며 원문 직역이나 원전 전문이 아닙니다. 역사 기록과 연의의 장면을 구분하고 날짜가 불명확하면 `approximate`와 설명을 사용합니다. 게임 발동 시기를 실제 발생 월로 확정하지 않습니다.

관리 화면은 `/admin/events`입니다. 편집한 선택·효과는 게임의 가상 분기이며 문헌의 사실로 취급하지 않습니다. 사용법은 [관리 안내](ADMIN_GUIDE.md), 공유 저장 연결은 [Firebase 설정](FIREBASE_SETUP.md)을 참고합니다.
