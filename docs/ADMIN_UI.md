# 관리자 화면 디자인

사용자가 제공한 [Flowbite Admin Dashboard 저장소](https://github.com/themesberg/flowbite-admin-dashboard)의 상단바·사이드바·카드 구성을 참고합니다. 공개 소스의 `layouts/partials/navbar-dashboard.html`과 `sidebar.html`에서 레이아웃을 확인했습니다. 참고 저장소의 라이선스는 MIT입니다.

## 적용 범위

`/admin/events`의 사건 편집 화면과 공유 저장 패널을 변경합니다. 밝은 회색 배경 위에 흰색 패널을 배치하고, 파란색으로 현재 메뉴·선택 사건·주요 저장 동작을 강조합니다. 서울한강체를 유지합니다.

사이드바는 사건 관리·사건 기록·게임·공유 저장으로 연결합니다. 요약 카드에는 실제 사건 목록에서 계산한 수량만 표시합니다. 사건 목록, 흐름 캔버스, 속성 패널은 각각 독립적인 카드로 구성합니다. 좁은 화면에서는 패널을 아래로 배치하고 모바일에서는 메뉴를 접어 사용할 수 있게 합니다.

기존 React와 CSS Modules로 구현하며, 샘플의 Hugo·Webpack 구성이나 Flowbite 실행 스크립트를 추가하지 않습니다. 관리 화면의 폼 상태와 React Flow 동작을 유지하면서 화면 구조와 스타일을 적용합니다.

## 유지해야 할 동작

- 사건 정보 저장과 실행 흐름 저장의 구분
- 조건·선택·결과 노드의 추가·이동·삭제·연결
- 잘못된 흐름 저장 차단과 미저장 변경 경고
- JSON 가져오기·내보내기와 브라우저 저장 복원
- 관리자 인증, 공유본 불러오기, 공유 게시 권한

UI 검증에서는 브라우저의 로컬 편집 기능을 시험합니다. 공유 목록 변경은 별도의 명시적인 게시 작업으로 수행합니다.
