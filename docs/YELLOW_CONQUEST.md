# 황건 천하통일 가상 시나리오

새 게임에서 **황건적 코스프레 → 황궁으로 가는 부대를 따라간다**를 선택한다. 거점 방어는 기존 5.1 전선을 유지한다. 이미 전선을 선택한 저장은 그대로 이어지므로 새 원정은 새 게임에서 진입한다.

원정은 `chapter-5-1-yellow-conquest` 안에서 **동탁군 → 유비군 → 조조군** 순서로 진행한다. 각 전투는 지력의 전략 판정과 통솔·무력의 전투 판정 중 하나를 선택하며, 해당 장수의 기존 능력치를 상대값으로 쓴다. 성공하면 적 세력 패망·거점 확보·다음 전투로 이어지고, 실패하면 플레이어 생포·처형으로 즉시 종료한다. 처형 이후의 전투나 성장 보상은 적용하지 않는다.

세 전투 승리 후 황제를 생포하고 황건국을 건국하는 마지막 선택으로 천하통일을 확정한다. `emperorCaptured`, `yellowEmpireFounded`, `yellowUnification`을 남기고 후한을 패망 처리하며 전체 등록 지역의 지배를 황건군으로 바꾼다. 결말 화면·연대기·궁정·소속·지도에 건국 결과를 표시한다. 일반 5.1 전투의 자동 결과가 원정에 끼어들지 않도록, 도입과 같은 순서값에서 도입을 선행 조건으로 요구하고 기존 전투 전에 원정을 처리한다.

이 원정은 사용자가 지정한 **게임 창작**이다. 184년·20세 테스트 안에 압축된 전개이며 실제 역사 연대, 사서 기록, 5.2 이후 수집 자료로 취급하지 않는다. 기존 수집 사실·연표·인물 연결은 변경하지 않는다.

분기 구조는 `scripts/build-chapter-5-1.mjs`, 문구 원본은 `data/history/narrative-5-1.json`, 실행·관리 화면은 `data/history/events.json`을 사용한다. 사건은 총 8개, 선택 장면은 25개, 행동 선택지는 65개다. 원정 진입·거점 방어와 세 전투·건국의 선택지 9개 및 원정 상황 장면 4개에 문맥에 맞는 픽셀 이미지를 연결한다. 기본 연결은 `data/history/conquest-artwork.json`, 사건별 설정은 선택 노드와 선택지의 `artwork`에 저장한다. 관리자 노드 속성의 상황 이미지·선택 이미지에서 경로·설명을 수정하거나 이미지를 숨길 수 있다. 기존 공유본에 이미지 설정이 없어도 기본 연결을 사용한다.

이전 공유본의 7개 목록은 도입 문구·제목·배치를 편집했어도 기존 노드·선택·효과를 유지하면서 황건 합류 직후에 새 원정 진입 선택과 원정 사건을 보완한다. 거점 방어 선택은 기존의 황건 합류 후 연결로 이어진다. 새 목록에서 의도적으로 원정을 삭제한 경우는 되살리지 않는다. 원정 진행 커서와 결과 표식은 기존 브라우저 저장 구조를 사용한다.

관리자 사건 관리에서 **죽창**, **황건**, **천하통일**, 사건 ID `chapter-5-1-yellow-conquest`, 내부 노드 ID `dong-plan`으로 검색할 수 있다. 직접 열기는 `/admin/events?event=chapter-5-1-yellow-conquest`다.

`lib/yellow-conquest.test.ts`는 8가지 승리 작전 조합, 세 전투×두 작전의 처형, 새로고침 복원, 중복 선택 방지, 조기 종료, 타 진영·거점 방어 분리, 구 공유본 호환성을 검증한다.

도입에서 주인공은 천하통일을 결심하지 않는다. 황궁으로 향하는 황건군 무리에 얼떨결에 섞인 뒤, 승리를 거듭하며 장교가 되고 마지막에 황건국 건국에 이른다. 이전 기본 문구가 공유본·로컬 편집본에 남아 있으면 알려진 구문만 필드별로 보완하며 관리자 작성 문구는 보존한다.
