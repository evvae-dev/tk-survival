# 3등신 픽셀 아트 기준

이미지 제작 시 [이미지 생성 규칙](IMAGE_GENERATION_RULES.md)을 먼저 적용한다.

기존 `public/title-screen.png`의 색감과 주인공(갈색 머리, 회색 반소매 후드, 청바지, 갈색 배낭)을 유지한다. 모든 후속 캐릭터 생성은 `public/art/characters`의 개별 기준 이미지를 참조한다. 3등신 비율, 선명한 픽셀, 남색 그림자와 따뜻한 호박색 조명을 유지한다.

- `protagonist.png`: 주인공
- `liu-bei.png`: 유비, 녹색·금색 의복과 관, 짧은 수염
- `guan-yu.png`: 관우, 붉은 얼굴·긴 수염·녹색 의복·청룡언월도
- `zhang-fei.png`: 장비, 짙은 수염·검은 갑옷·붉은 소매·창
- `cao-cao.png`: 조조, 짧은 수염·남색 갑옷·자주색 망토

`lib/choice-art.ts`는 5.1의 56개 선택지를 행동 문구별로 19개 장면 이미지에 연결한다. 공통 행동은 같은 이미지를 재사용한다. 새 관리자 선택지는 관련 이미지를 검토한 뒤 명시적으로 등록한다. 알 수 없는 선택지에는 임의의 이미지를 붙이지 않는다.

기준 이미지와 장면은 image_gen으로 생성했다. 생성 원본 두 장은 `/workspace/generated_images`에 보존했으며, 런타임에는 장면별로 추출한 PNG를 사용한다.

장수 이름은 기본 글자색과 굵은 글씨를 사용한다. 5.1에서 확인한 인물만 연결하며 일반 명사 `장수`, `전의` 및 문맥을 확정할 수 없는 일반어 동형 이름은 자동 연결에서 제외한다. 모호한 인명을 추가하려면 먼저 사용자에게 문맥을 확인한다.

## 상황 장면과 표정 개정

현재 상황 카드에는 `lib/scene-art.ts`가 사건·선택 노드별로 장면을 연결한다. 시작·유비 일행 만남·광종 야습·성벽 포위전은 `public/art/scenes`의 전용 그림을 쓴다. 공통 피란·지도·협상·매복·마무리는 행동 이미지와 공유한다. 알려지지 않은 사건에는 장면을 임의로 붙이지 않는다.

행동 이미지 19종의 주인공 표정을 재생성했다. 겁먹은 비명, 어색한 위장 웃음, 결의, 긴장, 능청스러운 매복, 항의, 안도 등 눈썹·입·땀 표현으로 감정을 구분한다. 기준 캐릭터의 머리·복장·배낭·3등신 비율은 유지한다.

페이지 확인은 `.agents/skills/playwright-page-check/SKILL.md`를 사용한다. 사용자 스킬 경로에도 같은 스킬을 설치해 다음 작업에서 재사용할 수 있게 했다.


## 황건 천하통일 원정 이미지 (2026-10-19)

- 동탁의 기준 이미지를 `public/art/characters/dong-zhuo.png`에 추가했다. 기존 주인공·유비·관우·장비·조조와 같은 3등신 픽셀 스타일을 사용한다.
- `public/art/choices/conquest-*.png` 8개는 원정 출발, 동탁·유비·조조군 상대 전략/전투, 황제 생포·건국을 서로 다른 행동으로 표현한다. 거점 방어는 기존 `yellow-supplies.png`를 재사용한다.
- `public/art/scenes/conquest-*.png` 3개는 동탁·조조와 결전 전 대치, 황제가 남은 궁궐의 항복 장면이다. 유비전 상황 카드는 기존 `yellow-face-generals.png`를 재사용한다. 현재 상황 이미지와 선택 행동 이미지를 구분하여 선택 팝업의 중복 이미지 생략 규칙에 걸리지 않게 한다.
- image_gen으로 제작했으며 생성 원본은 저장소 밖 `/workspace/generated_images/`에 보존한다. 주인공의 회색 후드·청바지·갈색 배낭에 누런 두건을 더해 황건 소속을 표시하고, 동탁·유비·조조와는 적으로 배치한다.
- 기본 연결은 `data/history/conquest-artwork.json`에서 관리하고 생성기가 `events.json`의 선택 노드·선택지 `artwork`로 결합한다. 관리자는 `/admin/events`의 노드 속성에서 상황 이미지와 각 선택 이미지의 기본 사용·직접 지정·숨김, `/art/` 경로와 대체 설명을 편집한다. 저장·JSON 가져오기·공유본에서도 설정을 유지한다.
