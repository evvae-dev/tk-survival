# 챕터 사건 원본 사용 규칙 — 2026-10-22

사용자 요청으로 기존 나무위키 5.1~5.5 수집 파일과 연도별 챕터를 폐기했다. 지금의 원본은 `docs/romance-three-kingdoms/chapters/NNN.md`다. 요청 범위의 회차를 파일 순서대로 개발한다.

1. 챕터 원본을 끝까지 읽고 주요 전개의 각 항목을 별도 사건으로 대응한다. 핵심 인물·배경·반응·결과·선후관계를 생략하지 않는다.
2. 로컬에 파일이 없으면 연결된 저장소의 최신 트리를 조회해 `chapters` 경로를 찾는다. 이번 원본은 GitHub `evvae-dev/tk-survival`의 `docs/romance-three-kingdoms/chapters/`에서 확인했다. 읽어 온 원본만 작업본에 추가하며 관계없는 원격 코드를 덮어쓰지 않는다.
3. 회차 번호와 역사 날짜를 구별한다. 월 미상은 `null`, 원본에 정확한 연도가 없는 중간 경과는 상대 순서·근사 시기를 명시한다.
4. 원본 사건의 요지는 `fact`와 생성된 `facts.json`에 보존하고 출처 파일·항목 번호·SHA-256으로 추적한다. 새로운 웹 수집이나 원사서 직접 대조를 했다고 과장하지 않는다.
5. 장수·세력·지역 ID는 기존 기준 자료를 사용한다. 동명이인, 특히 환관 장양과 장수 장양 같은 다른 인물을 이름만으로 연결하지 않는다. 확인되지 않는 인물은 이름으로만 둔다.
6. 선택·속마음·증거 확보 과정·가상 결과는 게임 창작이다. 이를 원본의 사실 문장에 섞지 않는다. 기본 전개가 현재 플레이 결과와 충돌하면 실행 결말을 분기한다.
7. 사실과 원본을 보강해야 할 때만 승인된 대상의 추가 자료를 조회하고 출처와 미확인 사항을 남긴다. 새 판본에 옛 나무위키 연표를 다시 주입하지 않는다.
8. 현재 요청은 1~3화다. 요청 밖의 회차를 구현하거나 공유 게시·운영 배포까지 임의 확장하지 않는다.
