# 5.1~5.5 소속·사건 진행

2026-10-19 최신 사용자 승인 범위: 5.5까지 Codex 직접 수집·게임 연결. 5.6 이후는 수집하지 않았다.

## 실행 범위

공통 목록 `data/history/events.json`에 사건 28개를 등록했다. 기존 5.1 사건 8개를 유지하고, 합류·이동 사건 4개와 5.2~5.5의 사건 16개를 추가했다. 인물 탄생·독립 사망 이벤트는 제외했다. 시작은 184년·20세이며 다음 연도로 넘어가면 나이도 증가한다.

나무위키 원사이트와 robots.txt는 직접 조회 실패했다. 공개 미러 본문을 기본으로 읽고, 부족한 전개는 위키백과로 보완했다. 원사이트를 읽었다고 표시하지 않는다. 원문·HTML 덤프를 보관하지 않고 한국어 요약·실제 조회 URL·절·접근 유형·라이선스를 수집 JSON에 보존했다. 우성의 난 관련 세부는 검색 발췌 근거이며 직접 본문 조회로 과장하지 않는다.

사용자 결정에 따라 연표의 장 배치를 유지하고 나무위키 상세의 전개를 우선한다. 장온 출정의 185/186년 차이, 유우 평정의 188/189년 차이 등은 `dateNote`에 남긴다. 한수 투항은 연표의 소식을 게임 기본값으로 사용하며 병력 해산·세력 패망을 추정 적용하지 않는다. 가룡의 진압 → 유언의 부임은 별도 사건으로 연결한다.

## 소속과 이동

- 5.1 결말 뒤 현재 위치에 따라 조조·유비에게 지원할 수 있다. 매력 수치가 기본 성공 확률이다. 합류는 병사부터 시작하며 장교로 자동 임명하지 않는다.
- 후속 장의 동탁·공손찬·손견 지원도 같은 규칙을 사용한다. 지역·성인 여부·지도자 사망·세력 패망·포로 상태를 선택 노출 조건으로 확인한다.
- 합류 성공은 실제 소속·역할을 저장하고 다음 장의 해당 세력 활동지로 이동한다. 실패는 거절 결과를 남기고 재야 이동 선택으로 이어진다. 새로고침과 선택 키 재전송으로 재추첨하지 않는다.
- 이미 소속이 있으면 유지와 이탈을 먼저 선택한다. 유지 시 해당 세력의 사건을 따라가고 다른 전선은 소식으로 받는다. 관련 없는 전투에 소속원을 순간 이동시키지 않는다. 재야는 다음 장의 사건 지역을 직접 고른다.
- 합류·이동·주둔 위치 보완·지원 행동과 반응은 게임 창작이다. 군주급 인물의 후대 독립 세력과 184~188년의 조정 내 군사 지위를 같은 역사적 독립 국가로 취급하지 않는다.
- 각 수집 사건의 개입은 개인의 지원 임무·피란·연락·행정 결과를 바꾼다. 이번에 추가한 후속 장에서 대전역의 승패·전국 점유까지 바꾸는 분기는 확정하지 않았다.

## 단일 기록과 모바일 (2026-10-20 갱신)

- PC 오른쪽과 모바일에 개인 행동·배경·실제 결말·소식을 하나의 기록으로 표시한다. 두 패널의 교대·자동 재정렬은 제거했다.
- `world.log`의 append 순서를 유지하며 `recordType`·`recordId`로 역할과 중복을 구분한다. `historyLog`는 옛 저장 복원 archive이며 같은 사건을 다시 표시하지 않는다.
- 배경은 관련 장면에 진입할 때, 결말은 현재 세계와 양립하는 결과 노드를 처리할 때 공개한다. 취소·구출·대체 승리 뒤 원래의 승리·전사를 덮어쓰지 않는다.
- 5.1의 실제 유비/조조 동행 선택이 군주 지원의 증거다. 지원 거절 뒤 185년 양주·기주·탁군을 직접 고른다. 이후에도 실제 접촉 표식을 사용한다.
- 16개 후속 사건마다 서로 다른 능력의 첫 행동과 성공/실패에 따라 달라지는 후속 선택을 등록했다. 최신 [연속성 기준](CAMPAIGN_CONTINUITY.md)에 따라 정식 소속의 연례 설문·명부 업무와 무관한 외지 기사 재생은 생략하며, 29번째 사건 `chapter-5-5-closing`에서 현재 상태를 정리한다. 과거의 공통 help/observe 설명을 대체한다.
