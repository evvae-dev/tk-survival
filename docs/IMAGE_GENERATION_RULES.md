# 이미지 생성 규칙

사용자가 요청한 이미지 제작 기준을 정리한 문서다. 이후 상황 이미지·선택지 이미지·캐릭터 이미지를 생성하거나 수정할 때 적용한다.

## 1. 스타일과 비율

- 모든 게임 이미지는 레트로 픽셀 아트로 제작한다.
- 캐릭터는 **3등신**으로 표현한다.
- 기존 타이틀 이미지와 저장된 주인공 이미지의 느낌이 자연스럽게 이어지도록 한다. 장면이 바뀌어도 같은 게임의 이미지로 보여야 한다.
- 기존 이미지의 픽셀 표현과 색감을 기준으로 일관성을 유지한다.

## 2. 주인공의 일관성

- 생성할 때 저장된 주인공 기준 이미지를 참조한다.
- 얼굴·머리 모양·머리색·복장·배낭 등 외형의 식별 특징을 유지한다.
- 현재 기준은 갈색 머리, 회색 반소매 후드, 청바지, 갈색 배낭이다.
- 상황에 따라 표정·자세·동작을 바꾸되 동일한 주인공으로 알아볼 수 있어야 한다.

## 3. 유명 장수의 기준 이미지

- 유비·관우·장비·조조 같은 유명 장수는 **캐릭터별 기준 이미지를 따로 저장**한다.
- 같은 장수가 다시 등장하는 이미지를 만들 때 저장된 기준 이미지를 참조해 외형을 통일한다.
- 얼굴·수염·머리 장식·복장·대표 무기 등의 특징을 유지한다.
- 새로 등장하는 유명 장수도 기준 이미지를 저장하고 이후 생성에 재사용한다.

## 4. 상황과 선택지에 맞는 장면

- 현재 상황 카드에는 문맥에 맞는 이미지를 연결한다. 선택 팝업은 새로운 행동 이미지가 있을 때만 표시한다.
- **현재 상황과 같은 이미지이거나 선택지들끼리 같은 이미지가 반복되면 해당 선택 팝업 전체를 텍스트만 표시한다.** 상황 카드는 이미지를 유지한다.
- 상황 설명·선택 행동·등장인물·배경을 함께 읽고 장면을 구성한다.
- 같은 사건이라도 전투·협상·피란·은신처럼 상황이 다르면 알맞은 장면을 선택한다.
- 주인공의 소속과 아군·적군을 먼저 확정한다. 황건적 편 주인공은 누런 두건 등으로 식별되게 하고, 관군과 맞서야 할 장면에 관군의 아군으로 그리지 않는다.
- 실제 등장 상대를 확인한다. 관우·장비와 맞서는 장면을 일반 황건적과 싸우는 장면으로 대체하지 않는다. 해당 전투에 없는 유명 장수를 임의로 등장시키지 않는다.
- 추격과 도주, 공격과 방어, 야습 준비와 돌격, 초병 깨우기와 초소 지키기를 서로 다른 행동으로 구분한다.
- 같은 선택지 ID가 여러 곳에 쓰여도 실제 문맥을 기준으로 연결한다.
- 공통 행동은 의미와 상황이 맞을 때 이미지를 재사용할 수 있다.
- 문맥이나 등장인물을 확실하게 판단할 수 없으면 임의로 연결하지 말고 사용자에게 물어본다.

## 5. 주인공의 표정과 감정

- **밋밋하거나 무표정한 얼굴을 반복하지 않는다.** 상황과 행동에 맞게 감정이 분명히 드러나야 한다.
- 눈·눈썹·입 모양과 몸짓으로 표정을 구분한다. 필요한 경우 땀·눈물 같은 표현을 활용한다.
- 선택지에 표시되는 작은 크기에서도 표정이 읽혀야 한다.
- 예: 도망은 공포·다급함, 위장은 긴장한 가짜 웃음, 전투는 겁먹은 결의, 매복은 긴장·잔꾀, 물자 수색은 기대감, 협상은 간절함, 휴식은 안도·기쁨.
- 감정 예시는 고정 표정 목록이 아니다. 실제 문맥을 우선한다.

## 6. 화면에서 확인

- 생성한 이미지는 실제 상황 카드와 선택 팝업에 연결한 뒤 확인한다.
- 주인공의 얼굴과 핵심 행동이 잘리거나, 이미지가 숨겨지거나, 장면 전환 뒤 잘못된 이미지가 남지 않도록 한다.
- PC·모바일·높이가 낮은 화면에서 이미지와 선택 버튼이 정상적으로 보이는지 확인한다.
- Playwright 검증은 `.agents/skills/playwright-page-check/SKILL.md`를 참고한다.
