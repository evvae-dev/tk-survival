# 선택별 능력 판정과 명성

통솔·무력·지력·정치·매력을 행동의 해결 방식에 따라 조합한다. 모든 전략을 지력%, 모든 접촉을 매력%로 고정하지 않는다. 각 선택의 `check.weights`, `difficulty`, `fameReward`, `fameReason`를 챕터 원본에 명시하며 `data/chapters/balance-review.json`에 150개 판정의 비중·난도·명성·근거를 보존한다.

## 확률

- 상대 없음: `Σ(내 능력 × 선택별 비중) / Σ비중 + 50 − 상황 난도`.
- 실존 상대 있음: `50 + (내 가중합 − 상대 가중합) × 전체 가중치 + 50 − 상황 난도`.
- 0~100%로 제한하고 소수 둘째 자리까지 표시한다. 기본 상황 난도는 50, 전체 가중치는 1.5다. 상대 능력은 장수 원본 자료를 사용하며 가짜 능력치를 만들지 않는다.
- 전투는 통솔·무력, 직접 일기토는 무력 중심이다. 증거 대조는 지력·정치, 군중 동원은 통솔·지력·매력, 정식 지원은 매력·정치처럼 행동별로 조정한다.
- 사전 증거가 실제로 준비된 분기는 난도가 달라진다. 예를 들어 공동 인수증이 있는 우회 배송은 없는 경우보다 성공률이 20%p 높다.
- 무력 96의 주인공과 등무 76의 일기토는 난도 50에서 80%, 화웅 92는 56%, 여포 100은 44%다. 기존 장수 능력은 바꾸지 않았다.

예를 들어 지력 40·정치 60·매력 90인 주인공의 첫 고발은 `40×0.6+60×0.3+90×0.1+50−75 = 26%`다. 같은 주인공의 모집 소문 접촉은 `90×0.7+40×0.15+60×0.15+50−38 = 90%`다. 주 스탯과 행동 난도가 모두 선택에 반영된다.

## 명성

판정 성공은 해당 선택의 `fameReward`를 지급한다. 단순 접촉은 4점 안팎, 전장 지원은 6~12점, 주요 인물 구출은 18~28점, 폐립 보류·여포 생포처럼 전개를 크게 바꾸는 선택은 최대 30점이다. 같은 A/B라도 실제 효과에 따라 다르며 근거를 함께 보존한다.

판정 실패는 예외 없이 **성공 보상의 정확히 절반을 차감**한다. +10의 실패는 −5, +7의 실패는 −3.5다. 0 아래로 내려갈 수 있으며 반올림·절삭·최소 0 보정을 하지 않는다. 전사·처형도 실패 차감에서 제외하지 않는다. 판정 없는 관망은 명성 보상·실패 차감이 없다.

게임 선택지에는 성공·실패 확률과 명성 변화를 표시한다. 확정 뒤의 결과 카드에도 실제 명성 증감을 표시한다. 관리자 능력 판정 노드에서 종류·스탯 비중·상황 난도·성공 보상·근거를 수정하고 저장할 수 있다.

## 결과·저장

미리보기는 추첨하지 않고 선택 확정 때 한 번 판정한다. 기록에는 당시 비중·난도·상대·확률·난수·성패·성공 명성 기준·실제 명성 증감을 남긴다. 같은 선택 재제출과 저장 복원으로 재추첨하거나 보상을 중복하지 않는다. 이전에 확정된 판정·명성·기록은 소급 변경하지 않는다.

기록 기본 간격은 5초다. 선택 결과는 재생 속도·글 길이와 독립적으로 5,000ms 표시하고 다음 카드로 넘어간다. `pendingResult.recordId/expiresAt`를 저장해 새로고침으로 결과 시간이 초기화되지 않으며, 5초 전에는 다음 선택이나 기록 넘기기로 결과를 생략하지 않는다. 게임 완료·전사 결과도 5초 표시 뒤 최종 화면을 연다.
