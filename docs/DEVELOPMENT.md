# 개발 구조와 상태 계약

> 2026-10-16 현재 활성 범위는 184년·20세 테스트와 5.1 실행 사건 7개, 상위 연표 6개입니다. 장수 1,000명은 유지합니다. 이전 연간 성장·전체 연표 설명은 당시 기록입니다. 현재 구현·저장·편집 방법은 [5.1 실행 문서](CHAPTER_5_1_RUNTIME.md)를 우선 확인하세요.

사건 전개·가상역사·사건 간 연결의 다음 설계는 [사건 인과관계 설계](CAUSAL_EVENT_DESIGN.md)에 정리했다. 현재 구현과 제안 사항을 구분하며 양양 전투·유비 의탁·유기 후계 사건을 예시로 든다.

`/admin/collection`은 `lib/collected-chapter.ts`를 통해 5.1 수집 JSON을 읽는 조회 화면이다. 기존 React Flow로 사건 간 연결·단계·게임 창작 후보를 표시하며 편집 저장소나 실행 엔진에는 쓰지 않는다. 모바일은 세로 배치를 사용한다. 조회 데이터의 실행 상태는 계속 `playable: false`다.

## 상태와 시간

`lib/game.ts`는 인물·세계·자료 타입과 이름 사전을, `lib/history.ts`는 검토한 사건의 읽기 전용 배열을 제공합니다. `lib/world.ts`는 세계 기본 진행과 소속 승계를, `lib/event-engine.ts`는 참가 조건·선택 효과·연간 활동을 담당합니다. `stores/game-store.ts`는 순수 상태 전이를 Zustand에 저장합니다. 이전 `lib/events.ts`는 최초 체험의 자료이며 현재 게임 경로에서 사용하지 않습니다.

시작 연도는 170~190년이고 나이는 10세입니다. `birthYear = startYear - 10`, `age = 10 + year - startYear`, `turn = year - startYear`를 유지합니다. 사건 선택은 같은 해에 머물고 `resolvedEventIds`와 현재 월을 갱신합니다. 월 미상 사건은 연말로 정렬하되 실제 월을 정하지 않습니다. 연간 활동을 선택해야 연도·나이·완료 연수가 각각 1 증가합니다. 280년 활동 후 내부 연도는 281년이며 완료 상태가 됩니다.

`getCurrentEvent`는 원본 상태를 변경하지 않습니다. 현재 해의 사건을 순서대로 검토하면서 참가하지 않는 사건의 기본 세계 효과를 투영하고, 참가 가능한 첫 사건 또는 등용 제안·연간 활동을 반환합니다. `resolveChoice`는 연도·사건·선택 ID가 모두 맞아야 적용합니다. 비활성 선택과 오래된 클릭은 원본 상태를 그대로 반환합니다. 사건 해결 직후 큐를 다시 평가하며 이미 지난 월의 사건으로 돌아가지 않습니다.

선택 효과를 적용한 뒤 해당 사건의 기본 세계 효과를 검사합니다. 선수 선택으로 바뀐 세계 전제를 기본 역사 효과가 덮어쓰지 않도록 `historicalGuard`와 분기 플래그를 사용합니다. 연간 활동 직전까지 남은 원격 사건도 적용하며, 개인의 지역과 관계없이 세계가 진행합니다. 소속 세력이 멸망하면 피란민으로 정리하고, 조조→위→진·유비→촉·손씨→오의 정당한 승계가 있을 때는 소속과 평판을 이어갑니다.

과거 세계를 생성할 때는 각 사건 연도에 이미 등장한 세력을 먼저 활성화한 뒤 사건 효과를 적용합니다. 원씨는 관도 패전 직후가 아니라 207년 후계자들의 죽음 뒤 기본 경로에서 종료하고, 유표·유장·장로의 거점과 군무 모집도 각각 208·214·215년 항복 뒤 바뀝니다. 가상역사 분기에서는 항복 대상·궁정·건국 세력의 실제 상태를 검사해 성립하지 않는 즉위·책봉·정복을 건너뜁니다.

한시적 집단의 활동 기간도 게임 모델에서 제한합니다. 황건 주력군은 184년 말 진압을 기준으로 185년부터, 반동탁 연합은 190~191년의 공동 활동을 기준으로 192년부터 활동 세력에서 제외합니다. 이는 황건 잔당 전체의 소멸이나 연합 해산의 특정 월을 확정하는 역사 사건이 아닙니다.

세계 패널의 주요 거점은 역사 지도가 아닌 간소 게임 모델입니다. 소유 세력이 패망하면 후계가 확인된 조조→위→진·유비→촉·손씨→오 거점은 승계하고, 정복 사건에서 지목한 거점은 그 사건의 주체에게 넘깁니다. 나머지는 새 지배자를 추측하지 않고 `지배 세력 미확인`으로 표시합니다. 궁정은 후한의 허창, 위·진의 낙양처럼 모델에서 확인된 현 왕조·위치만 표시하며, 이전 `courtAtXuchang` 플래그는 220년 선양의 전제 검사에 사용합니다. 이를 각 해 모든 지역의 실제 영토·수도 변화를 확정한 지도로 해석하지 않습니다.

## 출생·역할·선택

농민은 무력과 생업, 상인은 자금·수익·성인 물자 지원, 서생은 지력과 학습, 군인은 무력과 훈련, 사족은 매력·자금·평판 인맥에 이점이 있습니다. 현재 거주지와 소속은 실제 선택으로 바뀌며 출생지는 유지합니다.

입대는 18세부터 가능합니다. 군무는 활동 세력 소속 성인이 선택하고 평판을 10씩 얻습니다. 평판 40과 무력 또는 지력 60이면 장교가 됩니다. 등용 제안은 성인·능력 70 이상·대상 평판 20 이상의 인물에게 현재 소속과 다른 활동 세력에서 해마다 최대 한 번 발생합니다. 수락은 소속·거점·평판을 바꾸고 거절은 기존 소속을 유지합니다.

190년 낙양 사건은 성인에게 동탁·조조 합류와 피란을, 미성년에게 호송 동행·은신을 제공합니다. 진류의 성인만 반동탁군에 합류할 수 있습니다. 일반 합류나 지원은 개인의 삶에 영향을 주며 전국의 승패를 즉시 바꾸지 않습니다.

## 자료 전달과 화면

`data/history/events.json`을 게임과 사건 탐색에 사용합니다. `/api/history`는 한국어 사건을 연도·지역·세력·분류·검색어로 조회하는 기본 카탈로그 API입니다. 클라이언트 탐색은 관리자 편집본을 포함한 유효 카탈로그를 사용합니다.

게임의 천하 소식은 문헌을 바탕으로 정리한 사건 정보이며, 세계 패널은 기본 진행과 게임 창작/가상역사를 표시합니다. 선택 이후 세계가 달라도 문헌 기록 설명을 소급 변경하지 않습니다. 로그는 최근 120개를 보관합니다.

## 저장·검증·남은 작업

저장 키는 `tk-survival-game-v1`, schema version은 3입니다. 한글 지역·가정의 이전 값을 ID로 옮기고 새 필드를 생성하며, 이전 저장의 패망 세력 거점은 소유자 미확인으로 정리합니다. 이전 체험의 191년 완료 저장은 미완료로 복원합니다. 비동기 hydration 후 화면을 표시하며 `skipHydration`을 유지합니다.

`stores/game-store.test.ts`는 배경 차이·천도 연령·지역 조건·원격 세계 효과·중복 선택·이동·군무 승진·등용·월 미상·가상역사 후속 전제·저장 복원·111년 종료를 검증합니다. `npm run typecheck`, `npm test`, `npm run build`로 확인합니다.

남은 범위는 고령 인물의 수명·노화·사망·세대교체, 세력 AI, 전투·군량의 상세 모델, 개별 사건에 맞춘 참가 선택 확대, 수치 균형, Firebase 실제 프로젝트 연결 검증입니다. 연간 생업만으로 전체 기간을 진행할 수 있지만 이는 완성된 역사 전략 게임을 뜻하지 않습니다.


## 사건 카탈로그와 실행 플로

`lib/game.ts`의 사건 형식은 한국어 제목·내용·문헌명·사서 기록, 연월 정밀도, 지역·세력·관련 인물과 역사/연의 분류를 포함합니다. `source.record`는 한국어 기록 해설입니다.

`stores/event-catalog-store.ts`는 기본 사건과 브라우저 편집본·삭제 목록을 합쳐 유효 카탈로그를 만듭니다. 게임 생성, 현재 사건 조회, 선택 처리와 연말 세계 진행에 같은 카탈로그를 전달합니다. 카탈로그와 게임의 저장 복원이 끝난 뒤 플레이 화면을 표시합니다.

`lib/event-flow.ts`는 시작·조건·선택·결과·종료 그래프를 검증하고 실행합니다. 조건은 허용된 게임 필드만 조회하며 효과는 선언한 타입만 적용합니다. 실행 코드나 `eval`은 사용하지 않습니다. 결과 뒤에 선택이 이어지면 `game.flowProgress`에 사건과 선택 노드를 저장하고, 종료할 때만 해결 사건 목록에 추가합니다. 선택 키에 노드 ID를 포함해 이전 선택 버튼의 재전송을 막습니다.

플로가 없는 기본 사건은 기존 동작을 유지합니다. 플로가 존재하면 빈 세계 효과 목록도 명시적인 대체입니다. 기본 편집용 그래프가 모든 기존 사건의 실행 규칙을 복제하지는 않습니다. 190년 낙양 천도는 성인·아동 분기와 지역·소속·직책·평판 결과를 편집할 수 있는 대표 그래프를 제공합니다.

유효하지 않은 연결·순환·도달 불가 노드·조건·효과·중복 ID는 저장과 가져오기에서 거부합니다. 브라우저 저장본이 손상되면 해당 카탈로그 편집본을 적용하지 않습니다. 관리자 변경은 과거 세계 상태를 소급 재작성하지 않습니다.

Firebase 공유는 CatalogProvider가 접속 시 게시본을 불러온 뒤 하위 화면을 엽니다. 미게시 로컬 편집은 유지하고 게시 시에는 문서 업로드 후 포인터를 트랜잭션으로 교체합니다. 설정·권한·검증 범위는 [연결 안내](FIREBASE_SETUP.md)를 참고합니다.
