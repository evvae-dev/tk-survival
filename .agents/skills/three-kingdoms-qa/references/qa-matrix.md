# 경로 테스트 매트릭스

대상 사건과 변경 범위에 맞는 행을 선택한다. 범위 밖은 사유와 함께 제외하고 미실행을 통과로 표시하지 않는다. 모든 테스트는 고정된 시작 상태에서 재현 가능하게 작성한다.

| 경로 | 시작 상태·조작 | 기대 결과 |
|---|---|---|
| A 성공 | 미래 지식·증거·접근 조건 충족, 성공 분기 | 행동과 상대 반응이 서술되고 효과가 한 번 적용된다. 바뀐 전제에 맞게 후속 사건이 변경된다. |
| A 실패 | 같은 전제, 실패 분기 | 예고한 위험이 인과 있게 발생한다. 실패 결과에서 성공 효과가 적용되지 않는다. |
| B 접촉·임관 성공 | 실제 접촉/동행·생존·세력 조건, 매력 성공 | 접촉/임관 단계가 구분되고 소속·역할·다음 활동이 실제 결과와 일치한다. |
| B 거절 | 동일 전제, 매력 실패 | 거절 반응이 기록되고 소속을 잘못 부여하지 않는다. 유효한 후속 행동이 있다. |
| B 접근 불가 | 죽은 군주·패망·미접촉·다른 장소 등 | 합류가 열리지 않거나 실제 가능한 접근 준비로 대체된다. |
| C 생존 | 유효한 대기·피신 선택 | 이유 없는 처벌 없이 결과가 이어진다. 시간과 세계 변화가 반영된다. |
| 조건 경계 | 확정 조건 참/거짓, 최소치 방식이면 경계 전후 | 노출·잠금이 정책과 일치한다. 미달 상태에서 판정·턴·효과를 소비하지 않는다. |
| 확률 계산 | 실제 상대/상대 없음, 단일/복합 능력 | 현재 엔진 공식·가중치·상한/하한과 화면 표시가 일치한다. |
| 직접 연결 | check에서 result 없이 다음 choice로 이동 | 성공/실패의 실제 결과 서술과 인과 연결이 모두 남는다. |
| 분기 합류 | 성공과 실패 각각 공통 후속 노드 진입 | 어느 경로에서도 문장이 모순되지 않으며 이전 결과를 지우지 않는다. |
| 사망·포로·종료 | 각 결과가 발생하는 경로 | 불가능한 행동이 차단되며 종료 뒤 다른 선택으로 진행하지 않는다. |
| 미리보기·재제출 | 표시만 반복, 선택 확정 후 같은 요청 반복 | 미리보기는 추첨하지 않고 확정 결과·효과는 한 번만 적용된다. |
| 저장 복원 | 판정 후 저장→새로고침→복원 | 판정값·생존·소속·위치·기록 순서가 유지되고 재추첨·중복이 없다. |
| 관련/무관 사건 | 관련 소속·현지 재야·외지 소속 | 실제 참여 근거에 맞는 장면만 표시되고 순간 이동·반복 업무가 없다. |
| 관리자 | 대상 문구/조건/효과/연결 편집→저장→새로고침 | 편집이 유지되고 게임에서 같은 데이터로 실행된다. |
| 이전 편집본 | 기존 사용자 문구·연결·삭제가 있는 저장 | 기존 편집과 명시적 삭제가 보존되며 무단 전체 교체가 없다. |
| PC/모바일 | 선택·잠금·결과·기록을 실제 화면에서 확인 | 중요한 조건과 결과를 읽고 조작할 수 있으며 잘림·오류가 없다. |

## 사건 참여 연속 경로 — 2026-10-23

[참여 계약](../../../../docs/EVENT_PARTICIPATION_CONTRACT.md)의 구현을 검증할 때 적용한다. 아래는 기대 동작이며 현재 구현의 통과 기록이 아니다. 직전 사건의 실제 선택으로 시작하고 같은 능력치에서 성패만 달리해 비교한다. 표식 주입은 경계 검사에만 보조로 쓴다.

| 경로 | 시작 상태·조작 | 반드시 확인할 결과 |
|---|---|---|
| 접근·동행 허락 | 접근과 동행 요청을 순서대로 성공 | 허락된 다음 현장·선택만 열리고 이동 근거가 있음 |
| 접촉 성공·동행 거절 | 접촉 성공 뒤 동행 판정 실패 | 접촉 상태가 남아도 도원결의는 소식만; 현장 선택·이동·보상 없음 |
| 미접촉·관망 | 앞선 사건에서 접근하지 않음 | 자동 만남·동행 없음; 성립한 결의 소식 뒤 유효한 재야 경로 |
| 황건 합류 성공/실패 | 실제 접근 후 명시적 합류 시도 | 성공만 황건 시점; 실패 후 자동 가입·유비군 배치 없음 |
| 다른 진영의 대체 결말 | 황건 측 개입으로 적장 생존 결과 | 공통 종료·다음 사건·복원에서 고정 사망으로 덮어쓰지 않음 |
| 세계 전제 소멸 | 필수 인물·세력·전투 전제가 사라짐 | 원래 현장·승리·사망 없음; 정의된 취소/대체 후 진행 |
| 관련 불참/무관 불참 | 소식 관련성만 다른 두 상태 | 관련 소식만 카드 표시; 필요한 세계 효과는 누락·중복 없이 적용 |
| 권한 충돌 | 이전 허락 뒤 철회/거절/이탈 | 정의된 유효 범위·우선순위대로 허용; 낡은 표식으로 재진입 불가 |
| 불참 뒤 복원·재요청 | 소식 처리 경계 저장→복원→반복 요청 | 카드·효과·보상 중복과 진행 정지 없음 |
| 위조 선택 | 불참/다른 진영에서 숨겨진 현장 선택 키 전송 | 선택·판정·개인 상태 변경 없음 |
| 이전 저장·편집 | 확정 결과·열린 커서·조건 편집·삭제가 있는 저장 | 과거 결과 재판정·권한 추정·편집 덮어쓰기 없음; 호환 경로 확인 |
| 관리자·화면 | 참여 조건 변경→저장→복원→게임 | 진입 전 판정에 반영; 소식 카드 후 다음 사건; PC/모바일·이미지 일치 |

각 실행에서 `초기 상태 / 직전 선택 ID / 판정 결과 / 기대·실제 참여 방식 / 실제 노드 / 기록 유형 / 위치·소속·생존·개인 보상 변화 / 다음 사건 / 증거`를 남긴다. 선택지 수나 전체 사건 처리 수만으로 참여 분기를 통과시키지 않는다.

## 결함 기록 양식

```text
결함 ID / 심각도 / 확정·검증 필요·편집 제안:
사건 ID / 노드 ID / 선택 ID / 원문 위치:
초기 상태와 재현 절차:
기대 결과와 근거:
실제 결과와 증거:
플레이 영향:
수정 제안:
재검증 결과 또는 미실행 사유:
```

결함의 재현 증거는 관련 문장·상태 차이·테스트 출력·필요한 화면 캡처로 좁힌다. 사용자 실저장·인증 정보 등 불필요한 자료를 보고서에 포함하지 않는다.

## 완료 보고

- 다섯 평가 점수와 종합 점수, 확인 불가 항목.
- 심각도순 결함과 구체적 수정 방향, 상황 3~4문장·A/B/C의 리마스터.
- 실제 실행한 경로와 명령, 통과·실패·미실행 범위.
- 수정했을 경우 변경 파일·사건/노드 ID·회귀 검증 결과.
- 설계만 검토했다면 실행·화면·관리자·운영 검증은 수행하지 않았다고 표시.
